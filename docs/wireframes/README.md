# Wireframes - StockTrack Mobile Chirho

Estos archivos son wireframes de baja fidelidad para documentar el flujo principal de la app:

- `dashboard.svg`: pantalla inicial con metricas, estado offline y alertas.
- `products.svg`: lista de productos con busqueda y filtro.
- `detail-movement.svg`: detalle de producto, movimiento e historial.
- `product-form.svg`: formulario para crear o editar productos.
- `offline-sync-flow.svg`: flujo de persistencia local y sincronizacion.

Para insertarlos en Google Docs, abre cada SVG en el navegador y toma captura, o insertalos como imagen si tu navegador/Docs lo permite.
